Slide 8
Training reference and four-domain profiles
Reference: 16 training recordings; test matrix: ID + 22 numeric fields. Compare 21 fields, excluding duration of the evaluated window.
z = (value − mean) / sample SD. Below P10 → LOW; P10–P90 → NORMAL; above P90 → HIGH.
Domains: Duration (TST); Continuity (efficiency, WASO, awakenings, fragmentation); Initiation (SOL); Architecture (N1/N2/N3/REM %).
Any out-of-range metric marks its domain. 0 / 1 / 2 / 3–4 deviated domains → Within Reference / Mild / Moderate / High Deviation.
Dataset reference, not healthy norms. EEG deviations are displayed separately; profile levels are descriptive counts.
