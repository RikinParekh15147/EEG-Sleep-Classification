SLIDE 8

Role of Each Model Component
Source: HMC-PPT-20261007-01 | checkpoint_config.json, model_layers.csv
08
CNN downsampling
Convolutional filters learn local patterns; strides reduce 3000 samples to 188 feature positions.
Self-attention + feed-forward block
Four attention heads combine feature positions within each individual 30-second epoch.
Bidirectional LSTM
64 units in each direction model the downsampled within-epoch sequence.
Evidential output
Five nonnegative evidence values define Dirichlet means and total-evidence uncertainty.

Personalized Sleep Health Indicators
Source: HMC-PPT-20261007-01 | biomarker_equations.md, subject_biomarkers.csv
19
Evaluated-recording SE (%)
100 × non-Wake epochs / all evaluated epochs; a recording-duration proxy.
WASO (minutes)
Wake epochs between first and last sleep epoch × 0.5; excludes trailing Wake.
N3 proportion (%)
100 × N3 epochs / all evaluated epochs, including Wake in the denominator.
SFI (transitions / sleep hour)
N2/N3/REM → Wake/N1 transitions divided by hours scored as sleep; coarse stage-transition proxy.
No verified time-in-bed denominator; these indicators are research measures, not diagnoses.

Appendix — Weighted Viterbi Details
Source: HMC-PPT-20261007-01 | soft_viterbi_pseudocode.txt, transition_config.json
39
Aij = (1 + training transitions i→j) / row sum
πj = (1 + training countj) / (5 + Ntraining)
ptj = (etj + 1) / Σk(etk + 1)
D0j = log(πj + ε) + 0.9 log(p0j + ε)
Dtj = maxi[Dt−1,i + log(Aij + ε)] + 0.9 log(ptj + ε)
Store argmax predecessors; backtrack from argmaxj DT−1,j.
ε = 10⁻¹²; training-only transitions; class order Wake/N1/N2/N3/REM.
Restart at each recording or missing-epoch gap. This is weighted MAP Viterbi, not differentiable soft-DP.
