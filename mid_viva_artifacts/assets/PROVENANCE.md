# Supplied visual assets

The user supplied `om.png`, `rikin.png`, `santosh.png`, and `pdeuofficial_logo.jpg` in the project root.

The portrait cutouts were produced with the imagegen skill and built-in image generation tool. Each source was inspected before editing. The request was to remove the background, preserve the person's face, glasses, hair, clothing, pose and appearance, and return a transparent PNG without added text or objects. All three outputs were inspected and saved locally as `om_cutout.png`, `rikin_cutout.png`, and `santosh_cutout.png`. The original supplied files remain available.

The official PDEU logo is embedded directly from the supplied JPEG with its aspect ratio preserved. Its artwork was not regenerated. Portrait framing uses native PowerPoint image cropping.
